# Inventory Management System

Приложение для складского учёта и управления каталогом товаров.
Разработано на Python 3 с использованием PyQt6.

Курсовая работа по дисциплине «Объектно-ориентированное программирование», МТИ.

## Описание

Программа позволяет вести каталог товаров на складе: добавлять, редактировать и удалять позиции, выполнять поиск и фильтрацию по названию, категории и наличию. При каждом запуске фиксируется сессия пользователя, при выходе автоматически сохраняется отчёт о времени работы.

## Технологии

- Python 3.13
- PyQt6 6.11

## Требования к окружению

```
pip install PyQt6
```

## Запуск

```
py main.py
```

## Структура проекта

```
main.py                 - Точка входа, класс AppLauncher
main_window.py          - Главное окно приложения
entities.py             - Классы BaseEntity, Product, ProductRepository
custom_widgets.py       - Переопределённые компоненты PyQt6 (13 шт.)
custom_map.py           - Кастомная структура данных CustomMap (замена dict)
product_dialog.py       - Диалог добавления и редактирования товара
login_dialog.py         - Диалог авторизации пользователя
report_generator.py     - Генератор отчёта сессии в текстовый файл
```

## Функциональность

- Каталог товаров с 12 предустановленными позициями
- Поиск по наименованию, штрихкоду и описанию
- Фильтрация по категории и признаку наличия на складе
- Сортировка по цене и ID
- Добавление, редактирование и удаление товаров
- Боковая панель с детальной карточкой выбранного товара
- Складская аналитика: количество позиций, единиц и суммарная стоимость
- Отчёт сессии сохраняется в файл `session_report.txt` при выходе

## Выполненные требования ТЗ

1. Все сущности описаны через классы
2. Переопределено 13 компонентов PyQt6
3. Вся функциональность реализована через методы классов и @staticmethod
4. Сущности наследуются от абстрактного базового класса BaseEntity
5. Переопределено 10 специальных методов (включая __eq__, __repr__, __str__, __lt__ и др.)
6. Классы поддерживают операторы сравнения (<, >, <=, >=, ==, !=)
7. Все атрибуты классов имеют геттеры и сеттеры (@property / @setter)
8. Вместо dict используется кастомный класс CustomMap
9. Используется более 10 UI-компонентов
10. Хранение более 10 объектов в коллекциях list, tuple, set
11. Все компоненты выровнены через QGridLayout, QVBoxLayout, QHBoxLayout, QFormLayout
12. При закрытии приложения сохраняется отчёт сессии в формате ASCII-таблицы

Формат отчёта:

```
+---------------------------------------------------------+
| login       | time_in             | time_out            |
|-------------|---------------------|---------------------|
| Student_MTI | 11.10.2026 19:22:44 | 11.10.2026 19:25:10 |
+---------------------------------------------------------+
```
